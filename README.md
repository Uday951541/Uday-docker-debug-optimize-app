# Docker - Debug & Optimize a Broken Containerized App

## Project Overview

This project demonstrates how to build, debug, and optimize a containerized application using Docker.

The application consists of:

- Python Flask application
- Redis backend
- Dockerfile
- Docker Compose
- Docker health checks
- Docker Swarm
- Nginx service
